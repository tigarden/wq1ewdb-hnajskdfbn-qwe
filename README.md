# Debet.auto — Учет взаиморасчетов, запчастей и долгов

Современное адаптивное веб-приложение для ведения учета закупок автозапчастей, взаиморасчетов с поставщиками (Тотус, Эрнест, Витя и др.), заказов по автомобилям и расчетов с клиентами/мастерами («Другие»).

- 📱 **Работает на любом устройстве**: телефон, планшет, компьютер 24/7.
- 🌐 **Бесплатный хостинг**: развернуто через **GitHub Pages**.
- 🔒 **Приватность и безопасность**: данные сохраняются в репозиторий через GitHub REST API только под вашей учетной записью (`tigarden`).
- ⚡ **Оффлайн-режим**: сохранение в браузере при отсутствии интернета с автоматической синхронизацией при появлении сети.
- 📊 **Экспорт и бэкапы**: выгрузка в Excel (.xlsx) и JSON в один клик.

## 🚀 Как запустить веб-приложение на GitHub Pages

Репозиторий уже настроен: `https://github.com/tigarden/wq1ewdb-hnajskdfbn-qwe`.

1. **Отправьте код в репозиторий (Git Push)**:
   ```bash
   git add .
   git commit -m "Initial release of Debet.auto web app"
   git branch -M main
   git remote add origin https://github.com/tigarden/wq1ewdb-hnajskdfbn-qwe.git
   git push -u origin main
   ```

2. **Включите GitHub Pages в настройках репозитория**:
   - Перейдите в **Settings** репозитория на GitHub &rarr; раздел **Pages** слева.
   - В блоке **Build and deployment** &rarr; **Source** выберите:
     👉 **GitHub Actions**.
   - Готово! Через минуту сайт будет доступен по ссылке:
     👉 **`https://tigarden.github.io/wq1ewdb-hnajskdfbn-qwe/`**

## 🔑 Подключение сохранения данных через GitHub API

Чтобы только вы могли сохранять и изменять данные под вашей учетной записью:

1. Откройте приложение в браузере (на ПК или телефоне).
2. Перейдите во вкладку **«Настройки»**.
3. Создайте токен на GitHub:
   - [Создать токен GitHub (Fine-grained или Classic)](https://github.com/settings/tokens).
   - Для Classic Token: поставьте галочку `repo`.
   - Для Fine-grained Token: выберите репозиторий `wq1ewdb-hnajskdfbn-qwe` и права `Contents: Read and write`.
4. Вставьте токен в поле ввода и нажмите **«Проверить и сохранить токен»**.
5. Теперь все ваши записи автоматически сохраняются в репозиторий и доступны на всех ваших устройствах!
